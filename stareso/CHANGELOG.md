- 2026-10-21: new build profile `day <limit>` (default 2h): eco's loop with full autonomy while the user works on the same computer. It asks no question and skips and lists the slices that need the user. Every `check` and `shot` runs with `DAY_MODE=1`, so the idle gate opens a window only when the user has been away for a few minutes, and deferred windowed tests run once at the end of the milestone. The run stops at the wrap-up time (deadline minus 10 min) or at 80 % of the 5-hour or weekly usage window, and ends with `MILESTONE DONE: M<n> · next: M<n+1>` or `RUN STOPPED: <reason>` so that a manager session can relay the next milestone. The Claude Code argument hint lists `day <limit>`. DESIGN-NOTES records the manager-session proposal (not applied, to raise at the next retro). Reason: a build in `night` or `fast` mode stole the typing focus and cannot run while the user works.
