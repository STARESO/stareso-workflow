# Docs

What each file is for and which stareso-app skill writes it. Doc files are named in capitals; decision records are `decisions/NNNN-slug.md`.

| File | What it is for | Created by | Updated by |
|---|---|---|---|
| `../CLAUDE.md` | Short project rules for the AI assistant | setup | improve |
| `PLAN.md` | The decided app: single source of truth | init | grill, improve |
| `GLOSSARY.md` | Domain words: UI word, meaning, code name | init | grill, improve |
| `decisions/` | Why a hard-to-reverse choice was made | grill | improve |
| `IDEAS.md` | Inbox of raw ideas, each with a status mark | init | discuss, test, improve; build marks ✅ |
| `ROADMAP.md` | Milestones of small slices to build, with checkboxes and test markers | setup | improve, test; build ticks |
| `HELPER-RULES.md` | Rules for the helper agents that build slices | build | build, improve |
| `QUESTIONS.md` | Open questions the build could not answer | setup | build asks; improve and sessions answer |
| `FEEDBACK.md` | Test feedback and what became of it | setup | test |
| `BUILD-LOG.md` | One line per built slice, with date and time | setup | build |
| `FUTURE.md` | What comes next and what to watch (optional) | build (end of run) | build, improve |
| `DEPLOY.md` | Deployment checklist (once deploying) | deploy | deploy |
| `README.md` | This list | init | any skill that adds a doc |
